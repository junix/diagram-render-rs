$ diagram-render-rs --help
Render typed DBML, WaveDrom, D2, Structurizr, LikeC4, nomnoml, and Pikchr ASTs to SVG or PNG

Usage: diagram-render-rs [OPTIONS] [INPUT]

Arguments:
  [INPUT]  Input source/AST JSON file, or `-` for stdin [default: -]

Options:
  -o, --output <OUTPUT>                Output path. Without it, image bytes are written to stdout
  -f, --format <FORMAT>                Source language. Ignored for --ast-json [default: auto]
      --ast-json                       Treat input as serialized diagram_ast_parser::ast::Document JSON
  -T, --output-format <OUTPUT_FORMAT>  Output format. `auto` uses the output extension and otherwise SVG [default: auto] [possible values: auto, svg, png]
  -t, --theme <THEME>                  Colour palette: azure, mist-blue, sage, stone-teal, dusty-violet, warm-sand, olive-paper — each also as <name>-dark. Run `<bin> themes` for the full list. [default: light]
      --background <BACKGROUND>        Optional SVG/PNG canvas color. Omit for transparency
      --font-family <FONT_FAMILY>      Override the SVG font-family stack
      --scale <SCALE>                  PNG pixel scale. Ignored for SVG and when --width is supplied [default: 2]
      --width <WIDTH>                  Exact PNG output width in pixels
  -q, --quiet                          Suppress output summaries and non-fatal renderer warnings
  -h, --help                           Print help
  -V, --version                        Print version

Themes never paint a canvas: SVG and PNG output is transparent. A -dark theme is you asserting the host page is dark; the file does not adapt. Knock-outs — label halos, arrowhead interiors, opaque panels — are marks in the theme's page colour and inherit that assertion.
