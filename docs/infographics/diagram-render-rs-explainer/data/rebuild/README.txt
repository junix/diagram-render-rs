# data/rebuild — deterministic rebuild layer

Everything here is regenerated by the rebuild tool and must be
byte-identical across runs on this machine. Transcripts are
normalized: <work> scratch directory, <dur> durations, <ts>
timestamps. The rebuild asserts the seven re-rendered artifacts
hash-match data/frozen/artifacts before writing anything here.

Files:
  rerender-transcript.txt   normalized re-render transcript
  scene-stats.json          structured stats (equal to frozen values)
