01从类型化 AST 到像素

解析与渲染分仓：解析归兄弟项目，渲染归本引擎，场景原语层是两者之间唯一的交界。

场景原语是视觉边界

七种语言各自解释名字、层级与关系，之后只降维为六类绘图原语。数据库模式、时序波形、架构模型、分类图与几何场景本就不是同一类领域对象，所以这里没有「通用图模型」。

出双格式

SVG 由引擎自行发射，PNG 经开源 Rust 光栅化库 resvg 从同一份场景转换而来 —— 一次布局，两种产物。

依赖锁定

全部 7 项依赖均为 Rust 生态库；跨仓依赖 diagram-ast-parser（f34a45c…） · diagram-theme（1f77cb8…） 按修订精确锁定，仓独立可复现。

05渲染护栏（每一条都被实测触发过）

以下行为不是文档承诺，而是冻结探针的真实运行结果。

缩放闸门
有效缩放被限制在 0.05–16.0，越界直接拒绝渲染（双向实测触发）。
单边画幅上限
任一边超过 32,768 px 即拒绝；实测 32800x4800 请求被拒。
像素总量上限
总像素超过 100,000,000 即拒绝；实测 11072x9040（100,090,880 px）被拒。
精确宽度
--width 优先于缩放：实测请求 640，产出 640x418，分毫不差。
默认透明
7 张冻结 PNG 的角像素 alpha 全为 0；--background 实测才出现画布填充。
XML 转义
样例文本（unsafe & visible，含尖括号与 &）实测整体转义为实体输出，原始尖括号不出现；非有限几何直接拒绝。
禁用 unsafe
清单级禁令 + 源码扫描：全源码树 "unsafe" 唯一命中就是禁用声明本身。
降级明示
视图语法等有意不评估的行为以 warning 通道逐条告知（转录可查），--quiet 才静默；畸形输入以非零码拒收。
